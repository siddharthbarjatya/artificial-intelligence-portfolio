# Large-Scale Information Retrieval & Graph Database Systems

Two projects built on the same data: a Wall Street Journal news collection of more than 170,000 articles from 1990 to 1992 (the TREC WSJ corpus). One project answers "which articles match my query, best first", and the other answers "how are authors, companies, regions and topics connected".

| Project | What it solves |
|---|---|
| [BM25 Search Engine in R](bm25-search-engine-in-r) | Ranked keyword search over the full corpus, using an index stored on disk. |
| [Neo4j Graph Database](neo4j-graph-database) | Relationship-heavy questions about the corpus, expressed as short graph queries. |

The WSJ dataset is licensed material and is not included here.
