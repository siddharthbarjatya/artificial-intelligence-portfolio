# Adversarial Search & Evolutionary Agents

Two game-playing agents, each solving a different kind of decision problem.

| Project | What it solves |
|---|---|
| [XNimmt Minimax Alpha-Beta Agent](xnimmt-minimax-alpha-beta-agent) | Choosing which card to play in a card game where both players move at the same time and some cards are hidden. |
| [Snake Genetic Algorithm Neuroevolution](snake-genetic-algorithm-neuroevolution) | Evolving a neural-network controller for snakes that compete in a team game. |
